# University Project & Thesis Management System (UPTMS)

## About

UPTMS is a web-based system that manages the final-year project and thesis work of a university department in one place. Students, supervisors and the department administrator each get their own panel to handle research topics, proposals and project progress, instead of relying on manual paperwork and scattered messages.

It is the final-year project of the Department of CSE, World University of Bangladesh.

## Technology

| Part | Technology |
|---|---|
| Backend | PHP 8 (object-oriented, no framework) |

| Frontend | HTML, CSS, JavaScript, Bootstrap 5, Alpine.js |
| Dependencies | Composer |
